# Silkworm – Bullet Hell Arcade Game

A Java arcade game in the bullet hell genre, developed as part of the
"Programming 2" course (2nd semester, AI direction) at the
Deggendorf Institute of Technology (DIT).

## Features
- Real bullet hell experience at Standard difficulty
- Various powerups and enemies for a diverse play- and replay experience
- Selectable difficulty levels

## Tech
- Java, OOP, Software Architecture

## How to Play
The complete, runnable project is located in the
[`Abgabe_13`](https://github.com/Aequusss/Programmierung_2/tree/main/Abgabe_13) folder.

1. Download the repository (Code → Download ZIP) and open the `Abgabe_13`
   folder as a project in an IDE, preferably IntelliJ.
2. Run the program. If necessary, open the `StartGame` class in
   `src/thd/game/bin/` and run it.
3. Select a difficulty and play.
